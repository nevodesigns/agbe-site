Bulletin No. 01 Africa Deep Tech Challenge 2026 Domain: Agriculture Status: in build

An agricultural advisor that runs entirely on a $400 laptop with the network cable pulled out. No cloud, no API key, no data cost. Built for the machine that is already on the desk.

The problem

Advice exists. It just never reaches the field.

Nigeria has roughly one agricultural extension officer for every few thousand farming households. The knowledge that would raise a smallholder's yield is not secret and it is not new. It is written down in extension manuals, and it does not travel the last mile, because the last mile has no officer and often no signal.

The obvious answer is a farming chatbot. That answer breaks the moment you look at where farmers actually are. Rural coverage is patchy, mobile data is a real cost paid out of a thin margin, and a tool that needs the network is a tool that is absent on the morning the armyworm arrives.

So the constraint is not a feature we added. It is the shape of the whole thing: if it cannot answer with the network off, on hardware a farmer or a co-operative already owns, it does not count.

What it is

One small model, tuned hard, running locally.

AGBE is a compact language model fine-tuned on West and Central African agronomy and quantised to run through llama.cpp on commodity hardware. It answers questions about crops, pests, livestock, soils, storage and getting produce to market, in English and in Nigerian Pidgin.

The measurement

Why the biggest model that fits is the wrong answer.

The challenge scores submissions on a published formula. Accuracy is judged by people. Everything else is arithmetic:

Stotal = 0.50·Sacc + 0.30·Sperf + 0.20·Seff − Pthermal Sperf = min(TPS ÷ 15.0, 1.0) × 100 Seff = max(0, (7.0 − peak RAM GB) ÷ 7.0) × 100 Pthermal = 10 if the CPU throttles or exceeds 85°C

Read that carefully and it tells you what to build. Throughput above 15 tokens per second earns nothing. Memory is paid for linearly. So the instinct to pick the largest model that fits inside 8 GB is precisely backwards, and it is what most of a 1,598-strong field will do.

The 3B is the instructive row. It is the only candidate that misses the throughput bar outright, and its footprint collapses the efficiency term. It concedes 14.5 points to a 1B before a single question is asked, which it would have to win back by being twenty nine accuracy points better. It will not be.

Gemma 3 1B was chosen over a 0.5B for under one point of engineering, and over Llama 3.2 1B at identical file size purely because it holds 0.88 GB in memory instead of 1.26 GB.

The corpus

Nothing in the training data is unattributable.

No dataset ships with this challenge, so the training corpus is the real differentiator. It would have been faster to scrape the web or to have a large model write the answers. Both put claims into the data that nobody can trace, and this domain is graded by agronomists who will notice invented chemistry.

Instead every training pair is composed from a curated fact base of established extension practice. If a fact is not in that file, it cannot appear in the corpus.

  1. No invented numbers. No fabricated yields, no fabricated prices, and above all no agrochemical doses. Where a real answer needs a rate, it points at the product label and the local extension officer, because doses vary by product and a confident wrong number is dangerous.
  2. Local grounding. Crops, varieties, seasons and local names a farmer in the middle belt actually uses. Cassava mosaic, fall armyworm, striga, aflatoxin, Newcastle disease.
  3. Multi-turn. Judges hold a live conversation, so the model is trained on follow-ups: what if I cannot afford that, is it too late in the season, I tried that and it came back.
  4. Honest limits. Bacterial wilt has no chemical cure, and the model says so. Blossom end rot is a watering disorder, so it talks the farmer out of buying an insecticide.

What it will not do

Stated plainly, because a tool that hides its edges is worse than one that names them.

It will not give you a spray dose. It will not price your harvest. It is not a vet and it is emphatically not a doctor. It knows West and Central African smallholder systems and it will be thinner outside them. A 1B model is a knowledgeable extension pamphlet that can hold a conversation, not an agronomist, and where a real agronomist is available they are the better answer.
